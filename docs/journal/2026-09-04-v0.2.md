
# ALOE 0.2 : computer algebra

We’re taking an application-driven design approach with Aloe.

- Select an application to build in Aloe.
- Start building the application in Aloe.
- Add a feature to core Aloe only when the application requires it.

We’re doing this instead of adding features randomly or because we think they should be there.

For the Aloe 0.1 release, the driving application was a Boids simulator.

For the Aloe 0.2 release, the driving application is a basic computer algebra simplifier (a Cohen-style fragment in `examples/mpl/`).

To support that library we added two features to the Aloe core:

- protocols (class interfaces: a class can opt into a named protocol such as `Math`)
- method overloading on parameter types

Those are what the simplifier actually blocked on.
After the algebra could run, we added `show` so the REPL printed sends like `(x + 2)` instead of `#<Sum …>`. `:raw` keeps the old structural printer.

Primitive `Int` is not `Math`. Algebraic constants use `Num`.

## Examples

Here's some expressions that the computer algebra library handles:

```
(x * x)
; => (x ^ 2)

((x * 2) + (x * 3))
; => (x * 5)

((x ^ 2) * (x ^ -2))
; => 1
```
