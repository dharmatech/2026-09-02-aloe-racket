# Editor / LSP merge

Editor support has landed on local `main`: source locations, the shared
signature catalog, expression and completion queries, the LSP adapter, and the
VS Code hover/completion client. The landing also includes String `len` and
`take`, the Aloe-defined `starts-with?`, and the monomorphic Boid correction.

This landing does not include Gel-directory or Gel presentations. The default
drivers still receive no filesystem or terminal capability. Parser unification
and removal of Mirror and the earlier Gel are separate later projects.
