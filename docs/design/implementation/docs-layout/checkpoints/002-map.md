reader arriving there sees thirteen names. Each folder has a
`README.md` that records its own status, files, and identity, and
that README is the authority for its series. A map that lists every
folder with one line of purpose and one line of status, and defers to
the series README when the two disagree, is what the folder is
missing.

not: `racket-bytecode/`, `with/`, `parenthetical-construction/`,
`suite-jobs/`, and `suite-time/` still say "ready to implement" or
"in the working tree" for work that landed on `main` between
2026-09-30 and 2026-10-08. The discussion checked each against git on
2026-10-19 and found the landing commits. This slice refreshes those
five status lines with the facts, so that the map and the READMEs
agree on the day the map is written.
